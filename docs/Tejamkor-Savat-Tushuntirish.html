01 · Loyiha nima? Asosiy maqsad

Tejamkor Savat — oziq-ovqat isrofini kamaytirishga qaratilgan demo marketplace (onlayn bozor) prototipi. U Toshkent shahri uchun mo'ljallangan bo'lib, restoran va kafelarning kun oxirida sotilmay qolgan, ammo hali iste'molga yaroqli mahsulotlarini arzon narxda xarid qilish imkonini beradi.

Mijoz uchun

Sevimli taomlarini 50% gacha arzon olish, pul tejash va atrof-muhitga hissa qo'shish. Masalan: 60 000 so'm → 25 000 so'm.

Kafe uchun

Sotilmay qolgan mahsulotni utilisatsiya qilish o'rniga undan qo'shimcha daromad olish va mijozlar bazasini kengaytirish.

Jamiyat uchun

Oziq-ovqat chiqindilarini kamaytirish, resurslarning (suv, energiya, mehnat) behuda ketishining oldini olish.

Demo maqsad

G'oyani hakamlar, investorlar yoki foydalanuvchilarga tez va ko'rgazmali namoyish etish uchun tayyorlangan to'liq ishchi prototip.

E'tibor bering: bu to'liq demo. Barcha restoranlar, mahsulotlar, buyurtmalar, mijoz fikrlari va statistika xayoliy. Haqiqiy to'lov olinmaydi, kafe buyurtmani ko'rmaydi, hech qanday server yoki ma'lumotlar bazasi mavjud emas.

02 · Qanday ishlaydi? (foydalanuvchi yo'li)

Kafe e'lon joylaydi → Mijoz qidiradi → Savatga soladi → Band qiladi → Olib ketadi
1
Kafe mahsulot joylaydiKun oxirida yaroqli, lekin sotilmay qolgan taomni chegirma narxi, miqdori, olib ketish muddati va saqlash shartlari bilan e'lon qiladi.
2
Mijoz qidiradi va tanlaydiBosh sahifadagi qidiruv yoki /explore sahifasidagi filtrlar (kategoriya, tuman, narx, chegirma %) yordamida o'ziga mos taomni topadi. Muddati o'tgan mahsulotlar ko'rsatilmaydi.
3
Savatga soladiMahsulot detalida tavsif, allergenlar, tayyorlangan vaqti va qancha vaqt qolganligi ko'rinadi. Savatda miqdorni o'zgartirish yoki o'chirish mumkin. Mavjud miqdordan ortiq qo'shishga yo'l qo'yilmaydi.
4
Band qiladi (checkout)Ism, telefon (+998 XX XXX XXX XX formatida tekshiriladi) va olib ketish vaqti kiritiladi. Vaqt slotlari mahsulot muddati ichida 15 daqiqali oraliklarda avtomatik taklif etiladi. Natijada TS-XXXXXX buyurtma raqami beriladi.
5
Olib ketadiBuyurtma holati: Band qilindi → Tayyor → Olib ketildi. Agar bekor qilinsa, mahsulot miqdori qayta tiklanadi. Demo rejimda to'lov yo'q, buyurtma faqat brauzerda saqlanadi.

Hamkor va admin panellari

Hamkor kabineti (/partner): tanlangan restoranning buyurtmalari, taxminiy daromadi (10% platforma komissiyasi misoli), faol e'lonlari; mahsulot qo'shish/tahrirlash, mavjudlikni yoqish/o'chirish.

Admin panel (/admin): umumiy statistika (mijozlar, restoranlar, faol e'lonlar, rezervatsiyalar, demo aylanma), barcha buyurtmalar va restoranlarni boshqarish.

04 · Texnik tuzilma (qanday qurilgan)

QismTexnologiya / yechim
FrameworkNext.js 16 (App Router) + React 19 + TypeScript
StillarTailwind CSS 4, Turbopack tezlashtirish; maxsus ranglar: forest, fresh, accent, cream
Ikonkalarlucide-react
Holat boshqaruvBitta React Context (useStore) — butun ilovaning markaziy holati
Ma'lumotlar bazasiYo'q. Barcha ma'lumotlar brauzerning localStorageida (tejamkor:v1)
RasmlarReal rasm yo'q — FoodArt komponenti kategoriyaga qarab SVG illyustratsiya chizadi
VaqtMahsulot muddatlari joriy vaqtga nisbatan hisoblanadi; now har 30 soniyada yangilanadi

Fayl tuzilmasi

src/ ├── app/ → sahifalar (har papka = bitta manzil/route) │ ├── page.tsx, explore/, cart/, checkout/, orders/ │ ├── product/[id]/ → dinamik mahsulot sahifasi │ ├── partner/, admin/ │ └── about/, impact/, safety/, business-model/, ... ├── components/ → Header, Footer, ProductCard, FoodArt, │ DashShell, ProductForm, StatCard, ui, ... └── lib/ ├── store.tsx → butun ilovaning "miyasi": holat + barcha amallar ├── data.ts → 5 restoran, 14 mahsulot, 5 demo buyurtma ├── types.ts → Product, Order, Restaurant, CartItem tiplari ├── i18n.ts → tarjimalar (uz / ru / en) ├── format.ts → so'm formati, chegirma %, vaqt hisoblash └── status.ts → buyurtma holatlari va ularning ranglari

Asosiy ma'lumotlar modeli

  • Restaurant: id, nomi, manzili, tumani, telefon, tavsif, tarif (Bepul/Premium).
  • Product: id, nomi, tavsifi, kategoriyasi, restoranId, asl narxi, chegirma narxi, miqdori, mavjudligi, olib ketish muddati, tayyorlangan vaqti, saqlash sharti, allergenlar.
  • CartItem: productId + quantity.
  • Order: id, TS-raqami, mijoz ismi, telefon, olib ketish vaqti, elementlar, jami summa, holat, yaratilgan vaqti.

05 · Ma'lumotlar qayerdan keladi va saqlanadi

Generatsiya: src/lib/data.ts faylida 5 ta xayoliy restoran va 14 ta mahsulot ro'yxati bor. seedProducts() funktsiyasi mahsulotlarning tayyorlangan va olib ketish muddati vaqtlarini joriy vaqqa nisbatan hisoblab beradi — shuning uchun demo har doim "yangi" ko'rinadi, vaqt o'tishi bilan muddat tugamaydi.

Saqlash: ilk ochilishda localStorage bo'sh bo'lsa, demo ma'lumotlar yuklanadi. Keyingi o'zgartirishlar (savat, buyurtma, mahsulot tahriri, til) avtomatik ravishda brauzerga saqlanadi. Sahifani yangilashingizda hamma narsa o'z holatida qoladi.

Tiklash: "Demo ma'lumotlarni tiklash" tugmasi barcha o'zgartirishlarni boshlang'ich holatga qaytaradi (til tanlovingiz saqlanib qoladi).

Qulaylik: server talab qilinmaydi — saytni istalgan brauzerda ochib, to'liq sinab ko'rish mumkin. Cheklov: ma'lumotlar faqat shu brauzerda mavjud; boshqa qurilmada ko'rinmaydi va haqiqiy foydalanuvchilar o'rtasida almashilmaydi.

06 · Nima uchun bu loyiha kerak?

  1. Ijtimoiy muammoni ko'rsatish. Oziq-ovqat isrofi — global muammo. Loyiha uning oldini olishning oddiy va amaliy yo'lini namoyish etadi.
  2. G'oyani tez namoyish qilish. Hakaton, tanlov yoki investor uchun soatlab so'z o'rniga bosib ko'rish mumkin bo'lgan tayyor mahsulot.
  3. To'liq ishchi prototip. Faqat dizayn emas — qidiruv, filtrlar, savat, buyurtma, hamkor va admin panellari haqiqatan ishlaydi.
  4. Kengaytirish uchun poydevor. Keyinchalik haqiqiy qilish oson: store.tsx o'rniga API + ma'lumotlar bazasi, to'lov tizimi (Payme/Click), foydalanuvchi avtorizatsiyasi, real vaqt rejimi qo'shish mumkin.
  5. Ta'limiy qiymat. Next.js, React, TypeScript, Tailwind va holat boshqaruvni o'rganish uchun yaxshi namuna.

07 · Ishga tushirish va kelajak

Qanday ishga tushiriladi

Loyiha papkasida:

npm install → bog'liqliklarni o'rnatish npm run dev → ishlab chiqish serverini yoqish → http://localhost:3000

Boshqa buyruqlar: npm run build (ishlab chiqarish yig'ish), npm start (tayyor versiyani ishga tushirish), npm run lint ( kod tekshirish).

Kelajakda qo'shish mumkin bo'lganlar

  • Haqiqiy ma'lumotlar bazasi va server API (Supabase / PostgreSQL).
  • Foydalanuvchi ro'yxatdan o'tish va restoranlar uchun avtorizatsiya.
  • Haqiqiy to'lovlar (Payme, Click, UzCard) va buyurtma tasdiqlash.
  • Geolokatsiya yaqinidagi kafelar, xarita va navigatsiya.
  • Real vaqtli bildirishnomalar va buyurtma holatini kuzatish.
Xulosa: Tejamkor Savat — isrofga qarshi kurash g'oyasini namoyish etadigan, to'liq ishlaydigan, lekin butunlay xayoliy ma'lumotlarga asoslangan o'quv/taqdimot marketplace prototipi.
